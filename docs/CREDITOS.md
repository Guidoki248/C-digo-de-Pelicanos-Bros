# Créditos de imágenes · Pelícanos Bros

Las fotografías del menú provienen de **Wikimedia Commons** y se usan con fines académicos. Cada imagen fue recortada y redimensionada a un máximo de 900 px de ancho, y optimizada como JPEG para reducir el peso del sitio. No se alteró el contenido de la escena.

> Si publicas el proyecto, conserva esta atribución y enlaza a la página de cada archivo. Las licencias **CC BY-SA** exigen compartir las adaptaciones bajo la misma licencia.

## 4. Cómo volver a descargar una imagen

1. Abre el enlace de la columna **Fuente**.
2. En Wikimedia Commons, usa **Download original file** o el tamaño que necesites.
3. Guarda el archivo con el mismo nombre dentro de `img/platos/`.
4. Mantén la atribución de esta página.

> Las imágenes se incluyen únicamente como apoyo visual del prototipo académico. No representan necesariamente el producto exacto que se vende en Pelícanos Bros.
